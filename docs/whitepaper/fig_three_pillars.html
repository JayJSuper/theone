One principle, three faculties. Replace self-report with a machine-verifiable credential. In each pillar the self-report incumbent (LLM in-context reasoning · flat-embedding retrieval · acting on raw confidence) degrades systematically in the hard regime (high combinatorial load · high confounding · loose tuning), while the credentialed path holds. At the easy end of each axis the incumbent is fine — the value is regime-located, never average. Computation is research-grade (4 bases × 3 families, 1,207 pgmpy-verified truths); memory and metacognition are minimal-model demonstrations of the same shape, with the credential composing across pillars (memory inherits computation's de-confounded credential).
