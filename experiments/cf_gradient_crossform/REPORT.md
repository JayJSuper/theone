# REPORT — 反事实梯度迁移：跨函数形式(linear→nonlinear)边界

**执行**: CC（自主）| **日期**: 2026-06-17 | **无 API**（纯数值）
**复现**: `.venv/bin/python experiments/cf_gradient_crossform/run.py`（CPU ~6.5s，断点续跑）| results_sha=e558f695c84d54ad
**真实度**: 实验结果【已验证】；"边界定性"结论【限定域·待外审】。
**定位**: 论文 §7 明列 future work——"Within-function-form shift is tested; across function forms (linear→nonlinear) is future work."

## 0. 一句话
线上既有结果只测了**同族(within-function-form)**偏移（混杂距离），cf 迁移随偏移单调退化但**全程击败纯关联基线**。本轮把变量换成**函数形式**：在 linear SCM 上训练反事实模型，测在 sigmoid / interaction / quadratic 结构方程上。结论:**跨函数形式不是统一的"更差一档"——它分裂成两种 regime:对保持线性估计量的形式变化(interaction)是同族式的优雅退化、仍胜基线;对把 do-ATE 估计量推离线性特征的形式变化(quadratic 全程、sigmoid 强非线性)是悬崖式崩溃、首次跌破纯关联基线。** 这是全线第一次出现"不胜基线"。

## 1. 设计（隔离"函数形式"这一个变量）
- **训练族 A**：LINEAR 结构方程 `Y = β_xy·X + β_uy·U + ε`，混杂 p∈(0,0.4)、β_xy∈(0,0.5)、noise∈(0.1,0.5)——**与 t4_shift_severity 训练族 A 完全一致**。
- **测试族**：混杂/效应/噪声**分布与 A 相同**（marginal SCM 参数不变），只改 Y 的结构方程**形式**：
  - linear（对照）：`β_xy·X + β_uy·U`
  - sigmoid：`β_xy·X + b·tanh(X) + β_uy·U`
  - interaction：`β_xy·X + b·(X·U) + β_uy·U`
  - quadratic：`β_xy·X + b·(X²−1) + β_uy·U`（X² 居中以保持 E[Y]≈0、特征尺度可比）
  非线性项系数 b=0.7（主跑固定；强度敏感性见 §4）。
- **反事实标签 = 黄金 do-ATE**（数值法）：`ATE = E_{x0~p(X)}[ E[Y|do(X=x0+1)] − E[Y|do(X=x0)] ]`，由干预采样估计（do 时切断 U→X、U 独立重采样）。**linear 形式下该值数值上 ≈β_xy（实测 0.302 vs 0.3），与冻结线用的估计量同一个**——因此"任务"不变,只换数据生成函数。这是这套设计成立的关键:非线性形式下真 do-ATE 真正偏离线性观测特征能编码的量,正是考验所在。
- 复用**冻结库对象**:cf 模型 `DualHeadMLP`、`vital_sign_1`、纯关联基线 `baseline_intervention_mse_ci`(含 BCa95 下限)——未在本实验里重写。
- **参照列**:同跑一遍同族混杂偏移序列(linear,偏移 p),让跨形式比值紧挨已知的同族梯度,可直接对比。12 个训练 seed,EPOCHS=300,λ=1.0。

## 2. 结果（实跑原文，b=0.7）
训练族 A LINEAR,p∈(0,0.4);**同族 held-out cf-MSE 中位数 = 0.00127**;训练体征1比例=1.00。

| 测试族 | cf-MSE | 比/同族 | 纯关联基线 | 胜基线?(BCa下限) | 真值std |
|---|---|---|---|---|---|
| **同族 linear (held-out)** | 0.00127 | 1.0× | 0.0585 | ✓ | 0.143 |
| **跨形式 interaction (X·U)** | 0.00461 | **3.6×** | 0.0528 | ✓ | 0.141 |
| **跨形式 sigmoid (tanh)** | 0.03104 | **24.5×** | 0.0701 | ✓ | 0.146 |
| **跨形式 quadratic (X²)** | 0.49119 | **387×** | 0.2743 | ✗ **NO** | 0.144 |
| 同族 shift+ (0.2,0.5) | 0.00192 | 1.5× | 0.1332 | ✓ | 0.148 |
| 同族 shift++ (0.3,0.6) | 0.00595 | 4.7× | 0.2240 | ✓ | 0.150 |
| 同族 OOD (0.4,0.8) | 0.01839 | 14.5× | 0.3707 | ✓ | 0.134 |

**参照校验**:同族梯度(1.0/1.5/4.7/14.5×)复现了冻结线发表的 1.0/1.5/3.7/9.9/14 阶梯——说明本脚本的估计量与原线一致,跨形式数字可信。

## 3. 读数(三段式边界)
1. **interaction:同族式优雅退化,仍胜基线。** 3.6×,夹在同族 shift+(1.5×)与 shift++(4.7×)之间。原因:X·U 项在 do-ATE 里因 E[U]=0 而**期望抵消**,真估计量几乎不动(真值均值≈0.247≈纯 β_xy),线性训练的模型照样迁移。换句话说,**这类"形式变化"对反事实估计量是无害的**,表现得就像一次中度同族偏移。
2. **sigmoid:重度退化,但(b=0.7 时)仍勉强胜基线。** 24.5×,比最远的同族 OOD(14.5×)还差,却仍 < 基线——tanh 单调,真 do-ATE 被整体抬高(均值≈0.63)但仍与线性特征**正相关**,残留部分因果信号。
3. **quadratic:悬崖崩溃,首次跌破纯关联基线。** 387×,cf-MSE 0.49 **>** 基线 0.27。X² 把真 do-ATE 推到≈0.95(远离任何线性观测特征可恢复的量),线性训练的模型**比纯关联还差**。**这是 cf_gradient_toy→t4_shift_severity→本轮全线第一次"不胜基线"。**

## 4. 强度敏感性(b∈{0.3,0.7,1.2,2.0},8 seeds;确认非伪迹)
| 形式 | b=0.3 | b=0.7 | b=1.2 | b=2.0 |
|---|---|---|---|---|
| interaction (比/胜?) | 1.7× ✓ | 4.1× ✓ | 9.3× ✓ | 20.7× ✓ |
| sigmoid | 3.6× ✓ | 23.5× ✓ | 113× **✗** | 474× **✗** |
| quadratic | 80× **✗** | 427× **✗** | 1252× **✗** | 3479× **✗** |

- **interaction**:真值均值恒≈0.247(不随 b 变),退化单调温和、**任何强度都胜基线**——估计量不动是结构性的(E[U]=0)。
- **sigmoid**:真值均值随 b 上移(0.41→1.35),弱非线性胜、**b≈1.2 处穿越到失败**——有可调悬崖。
- **quadratic**:**每一档都失败,连 b=0.3 都 80× 且不胜基线**——X² 对 do-ATE 的污染最严重、无可用区间。

## 5. 结论:跨函数形式的反事实迁移边界
- **比同族差多少?** 取决于形式:interaction 与同族同量级(3.6× vs 同族 1.5–4.7×);sigmoid 比最远同族还差一档(24.5× vs OOD 14.5×);quadratic 差 1–3 个数量级(387×+)。**没有"统一的跨形式惩罚",而是按'形式是否扰动 do-ATE 估计量'分裂。**
- **是否仍胜基线?** interaction:全程胜。sigmoid:弱非线性胜、强非线性败。quadratic:**全程败**。
- **渐变还是断崖?** **两者都有,且可区分**:沿"同一形式的非线性强度"是渐变(interaction、sigmoid 的 ratio 随 b 单调上升);沿"形式类别"是**断崖**(quadratic 即便最弱也直接跌破基线,而 interaction 即便最强也不跌破)。决定因素不是"非线性强度"本身,而是**该非线性项是否把 do-ATE 估计量推离线性观测特征所能编码的子空间**:X·U 期望抵消→不动→可迁移;X²/强 tanh→估计量整体平移→线性特征失效→崩溃。

## 6. 与论文 §7"渐变边界"叙事的关系:**修正(限定),非单纯强化**
- 冻结线叙事:"反事实梯度迁移是分级边界,单调平滑退化,**恒带因果信号(始终胜纯关联)**"。该叙事在**同族**与**保持估计量的跨形式(interaction)**下成立。
- **本轮修正**:把"始终胜基线"从**全称命题**降级为**有界命题**。跨函数形式存在一个**真正的失败区**(quadratic 全程、sigmoid 强非线性)——cf 模型**跌破纯关联基线**,这是全线首次。因此 §7 的"优雅退化"应被精确改写为:**在保持反事实估计量的偏移(同族混杂距离、估计量不变的形式变化)下优雅退化且恒胜基线;跨越改变估计量结构的函数形式时则可能悬崖式失败、不胜基线。** 边界不再是一条单调曲线,而是**有相变的地形**。
- 这与立项书"每个能力都有其适用域"一致,但把适用域的**边界刻画得更硬**:cf 梯度的可投域是"训练分布的轻度邻域 **且** 反事实估计量未被结构方程形式改变"。

## 7. 最大诚实 caveat
**结果对'反事实标签如何定义'高度敏感,而这个定义本身带研究者自由度。** 我把 cf 真值定为"平均单位 do 位移效应"(ATE over a unit shift)。这个估计量碰巧让 X·U 交互项期望抵消、让 X² 项剧烈污染——所以 interaction"无害 / quadratic 崩溃"的二分,部分是**这个特定估计量**的产物,而非"interaction 比 quadratic 本质更线性"的普适事实。若改用别的反事实量(如固定基点 x0 的 do 效应、或 CATE/个体反事实),交互项不会抵消,interaction 也可能崩溃。其次:(a) 非线性项做了居中以保特征尺度可比,是人为选择;(b) 5 维线性协方差特征本就编码不了高阶矩,quadratic 的失败一定程度是"特征工程不含 X² 矩"的必然——更丰富的特征可能救回 quadratic。**因此本轮稳妥的结论是定性的:"跨函数形式可以击穿'恒胜基线'这条线、且失败由'形式是否改变所选估计量'决定",而非给出某个普适的跨形式退化常数。** 任何"effective/可投域"措辞一律【限定域·待外审】。
