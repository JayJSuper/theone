# REPORT — 原生因果隐空间·探针1:连续/非线性系统里的可验证 do(防玩具陷阱)

**日期**: 2026-06-19 | **类型**: 底层突破第一块可验证地基(朝"原生因果隐空间") | 5 小时深化产物
**复现**: `.venv/bin/python experiments/native_causal_latent/run.py`

## 0. 一句话
下一代方向是"因果作为连续隐空间的内生结构",而非外挂离散引擎。那份外部构想的 `hcos/causal.py` 用**线性下三角 SCM**做这件事——有闭式 do、无组合负荷,是玩具(判据 1/2 平凡通过)。本探针问真问题:**当系统连续且非线性(有真正的边缘化积分)时,do 还能否精确+可终止+可独立复算?** 答案:**能**。

## 1. 设计(连续混杂 + 非线性结果,防玩具)
- U ~ N(0,1) 连续混杂;X ~ Bernoulli(σ(1.2·U));Y ~ Bernoulli(σ(1.5·X + 1.8·U))。**非线性(sigmoid)、有真正的连续积分**。
- 真值 do(X=1) = E_U[σ(1.5 + 1.8·U)],无闭式解。
- "引擎"扩展:把 U 离散到 m 个等概率分位 cell(取条件均值代表),精确边缘化 do(X=1)=Σ P(cell)·σ(...)。

## 2. 结果(三条缺陷判据全 PASS)
| 量 | 值 |
|---|---|
| 连续真值 do(X=1):quadrature vs Monte-Carlo | 0.726799 vs 0.726848,**独立一致 |Δ|=4.9e-5** |
| 观测 P(Y=1\|X=1) | 0.840756 → **do−obs = −0.114**(因果≠相关,真实 gap) |
| 离散化 do 收敛 | m=2 误差 5.98e-3 → m=128 误差 **3.38e-5**(单调收敛) |

- **[判据1 可终止精确]** 每个有限 m 精确、随 m 单调收敛 → PASS
- **[判据2 因果方向]** do(0.7268) ≠ 观测(0.8408)、gap 可复算 → PASS
- **[判据5 可复算]** quadrature vs MC 一致到 4.9e-5 → PASS

## 3. 含义
- **The One 的可验证因果不止于离散 CPT,可延伸到连续/非线性系统**:do 通过"可终止的有限离散化 + 随精度收敛 + 独立复算"保持可验证。正面回应论文 §6.4/§7 标注的"连续变量=future work"边界——这是第一个可验证结果。
- **防玩具达成**:用了真正的连续积分(非线性 sigmoid),不是线性闭式解;若换线性,所有 m 都平凡精确、看不出收敛的意义。
- **朝"原生因果隐空间"的第一步**:下一步是把"离散化"换成可学的连续表征(神经编码),并仍用判据 1/2/5 自检——能否在学到的连续隐空间里保持可验证的 do,是真正的难点(也是与那份构想"线性玩具"的分水岭)。

## 3b. 探针2:连续组合悬崖 + 结构塌缩性(`run_highdim.py`)
把组合悬崖从离散推广到连续 k 维混杂,并区分两种负荷:
- **可分离** Y=σ(bX+Σc_iU_i):朴素离散化 m^k(k=5→7776 格)vs **一维结构塌缩**(Σc_iU_i~N(0,‖c‖²)),一致(残差=m=6 离散化误差)。**可分离负荷=假悬崖**:结构把 m^k 塌缩到一维(变量消元的连续版)。
- **不可分离** 加交互 d·U0·U1:朴素 m² vs **真 2D 积分**一致;**若错误假设可分离→误差 0.027**。**交互负荷不可塌缩=真连续组合悬崖**。
- **启示(判据1)**:原生因果隐空间必须 (a) 学到**塌缩可分离负荷**的结构(否则浪费 m^k)、(b) **检测并声明不可塌缩的交互负荷**(拒答/标注不精确,而非假装)。这是离散组合悬崖(变量消元绕可分离、真 treewidth 不可绕)的连续版,直接指引"原生隐空间该学什么"。

## 3c. 探针3:从数据**检测**可塌缩性 + 证伪闭环(`run_detect.py`)
探针1/2 假设分析者**已知**结构。原生因果隐空间必须**从数据发现**哪部分负荷可塌缩——判据1(a)落地的第一步。有限样本(检测带真实统计不确定性,防玩具):
- **检测器(可第三方复算,非黑箱)**:自写 Newton-IRLS 拟合带 U0·U1 交互的 logistic,verdict = 交互项的似然比检验(d=0?)**两路交叉验证**(LR 检验 + bootstrap 99%CI),两路一致才采信、分歧则 ABSTAIN 付全价(安全默认)。
- **证伪闭环**:按 verdict 行动(SEP→廉价 1D 塌缩;NONSEP→付 2D 积分),再与真值 do 比。结果:SEP(d=0)→检测 SEP、1D do 误差 0.003;NONSEP(d=1.4/0.5)→检测 NONSEP、2D do 误差 0.007–0.010;弱信号小样本(d=0.5,N=600)仍检对、误差 0.032(估计噪声)。四例两路全一致。
- **盲区案例(决定性诚实点)**:Y 含检测器**未建模**的非线性 g·(U0²−1)。检测器输出 NONSEP(U0² 曲率经混杂投影到 U0·U1 项,p_lr=2.5e-6),但**即便付了 2D 积分,do 仍残差 0.017**——因拟合**函数族**本身缺 U0² 项。**真正的盲区不在"可分离 vs 不可分离"二分,而在建模的函数族本身**;只有对真值的独立复算(判据5)能暴露它。这是 NOTE-004"computation-exact, structure-assumed"边界在连续隐空间的**函数形式层**版本。
- **教训**:判据1(a)"学到塌缩负荷的结构"可从数据经**可复算的可分离性检验**达成,且诚实(误检被独立积分器暴露);但检验只认证它**建模的形式**,可独立复算(判据5)才是真正的兜底,而非检验本身。

## 3d. 探针4:**可学**连续因果隐空间——可验证+声明+收敛的残差(`run_learned.py`)
探针1–3 用分析者对混杂的知识。原生因果隐空间必须从**混杂不可观测**的数据里**学**调整表征。防玩具:若直接观测 U,调整平凡、do 免费精确;诚实测试=**U 潜变量,只观测噪声代理** P_j=α_j·U+ε_j。可学隐空间=代理上的后门调整(拟合 logistic Y~[1,X,P],系数即学到的编码器),g-formula 估 do(X=1)=E_P[σ(β0+βx+β·P)]。
- 真值 do=0.7268,观测 0.8278(混杂偏差 **0.101**)。可学隐空间:p=1→残差0.034,p=8→**0.0095**(把偏差砍 10 倍);σ=0.4 更干净→0.0021,σ=1.5 更噪→0.0285。**收敛**:代理越多/越干净残差越小。残差可复算(split-half Δ~1e-3)。
- **关键诚实定位(是论点不是 caveat)**:可学隐空间over不完美代理**不让 do 精确**——混杂测量误差留真实残差(已知难题)。可信不在"魔法精确",在残差**有界、随证据收缩、可独立复算**——vs LLM 断言单个混杂与否的数、对"错多少"无可复算把手。这把判据 1/2/5 带入**可学表征**:原生因果隐空间的职责不是魔法精确,而是**可验证、声明、随证据收敛的残差**。

## 3e. 探针5:端到端**系统**——凭证 + 答/弃决策(`run_system.py`)
把探针1–4 合成一条管线,直面部署诚实问题:**真实世界不知真值**,凭证只能携带**无需真值即可验证**的自检:检测器两路一致性(探针3)+ 复算 gap(探针4)+ bootstrap CI(采样方差)+ **代理子集发散(新,truth-free bias 指标)**。决策:仅当复算 gap 小**且**子集发散小才 ANSWER(带声明 CI),否则 ABSTAIN——**绝不输出 confident-narrow-wrong 的数**。
- **决策 5/5 正确**(ANSWER 当且仅当真残差小,真值仅用于评估):clean/ok/interact(真残差0.004/0.003/0.002)→ANSWER、CI 覆盖真值;noisy(0.031)→ABSTAIN;sparse 单代理→ABSTAIN。
- **核心发现①**:bootstrap CI 只抓采样**方差**、不抓测量误差**bias**——noisy 场景 CI **窄(0.012)却不覆盖真值**=confident-narrow-wrong 失败模式(不可上线)。CI 单独不是答的许可。
- **核心发现②**:truth-free 的**子集发散**(逐一丢代理重估 do 的极差)**追踪 bias**:`corr(子集发散, 真残差)=+0.97`(4多代理场景,方向性证据)。小when干净、大when噪声/稀疏;决策据此在 proxy-不完整 bias 高时正确 ABSTAIN,**无需真值**。
- **诚实边界**:子集发散是**必要非充分**——抓 proxy-不完整 bias,不抓所有代理**共享的同一** bias(相关测量误差)。残差="variance-bounded, bias-partially-certified"=NOTE-004"computation-exact, structure-assumed"的**系统级继承者**。凭证精确声明它认证什么、越界即弃答,而非断言一个数。

**原生因果隐空间线小结(探针1→5)**:可验证 do 从①离散→连续/非线性,②区分可塌缩(假悬崖)vs 不可塌缩(真墙),③从数据**检测**结构(且函数族盲区被判据5暴露),④从数据**学**表征(残差有界/收敛/可复算),⑤合成**端到端系统**(凭证 + 答/弃决策,truth-free bias 指标 corr +0.97,从不 confident-narrow-wrong)。一条防玩具、步步接判据、步步可证伪、最终收口成可决策系统的地基,直指"原生隐空间该学什么、怎么保持可验证"。

## 3f. 探针6:B1 命门 —— 神经网"学到的"隐空间能否保持可验证 do(`run_probe6.py`)
B 线第一块硬骨头的最小验证(纯 numpy MLP、CPU)。混杂只能通过**非线性代理** P_j=tanh(a_j·U)+噪声观测(线性调整必偏),问:小型 MLP 编码器学到的连续隐空间里,do 还能可复算+收敛+诚实弃答吗?
- **结果**:真值 0.7268;**线性调整残差 0.0212 → 学到的 MLP 隐空间残差 0.0133**(赢);MLP do **split-half 复算 gap 0.0068**(判据5);truth-free 子集漂移 clean 0.0016→noisy 0.0039(代理变差时上升=弃答把手)。
- **B1 最小命门三条全 PASS**:学到的隐空间胜线性 · do 可复算 · 漂移随不足上升。
- **意义**:神经网**学到的**隐空间能保持可验证 do——B1 论点在最小尺度成立,**值得上真数据+GPU 正式走**。诚实范围:合成非线性代理数据、CPU 小 MLP,非真实尺度;过=路值得扩,不过=即知何处转向。对接 `docs/THE_ONE_BLINE_PLAN.md` B1。

## 3g. 探针7:B1 深化 —— 多混杂 + 对不可观测混杂诚实声明(`run_probe7.py`)
两个潜混杂 U1,U2,各只经非线性代理 tanh(αU)+噪声观测;更大 MLP(H=32)。
- **A 双混杂全代理(8 代理)**:学到的隐空间 do(1)=0.749 残差 0.033、复算漂移 0.004 → 可验证。
- **B 扩展性**:残差随 n=4k/12k/36k 大致收缩(路可扩,有训练噪声)。
- **C 一个混杂完全无代理(真不可观测)**:do 有偏(残差 0.092);**观测代理间漂移仅 0.0003——无法察觉"没有代理的东西"(信息论硬边界/NOTE-004)**;故不假装,**声明 unobserved-confounding uncertified + E-value 界 3.48**。
- **B1 深化门三条 PASS**:多混杂可验证 · 随数据收缩 · 不可观测混杂"有偏但不假装、声明+E-value 量化"。
- **意义**:学到的隐空间对**观测得到的**可验证、对**观测不到的**诚实声明+量化——B 线纪律在更难处守住。诚实范围:numpy MLP 合成数据 CPU。对接 plan B1。
