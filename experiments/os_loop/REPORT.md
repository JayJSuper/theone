**日期**: 2026-06-14 | **柱**: 操作系统 / 集成层（此前 ~5%，纯原型） | **无 API** | **真实度**:【已验证·演示系统】
**复现**: `python experiments/os_loop/run.py`

## 0. 一句话
把三柱接成**一个可运行的循环**:查询 →(记忆)按因果签名检索模型 →(计算)可识别性门 + 引擎精确估计 →(独立验证)pgmpy 在全模型上复算真值、引擎仅用观测变量的答案须匹配 →(元认知)据可识别性/验证/假设标志决定 **回答 / 带保留回答 / 拒答** → 输出完整可审计凭证。**The One 从"三个分立实验"变成"一个带凭证的认知系统"。**

## 2. 三柱在一次循环里如何咬合
- **记忆(柱2)**:按**因果签名**(treatment/outcome)检索模型,非表面文本;检索失败 → 拒答(不硬编一个模型)。
- **计算(柱1)**:可识别性门先判 do 是否可从**观测**变量识别(后门/前门/IV/拒绝);可识别才让引擎出数,数永远来自引擎。
- **独立验证**:pgmpy 在**全模型**(含未观测变量)上算真 do;引擎**仅用观测**的答案须匹配——前门案例正是"不观测混杂也复原真值"的验证。
- **元认知(柱3)**:不可识别 → 拒答+点名缺失变量;前门/IV → 带保留回答+标注不可验证假设;后门且复算一致 → 回答;复算不一致 → 拒答(不发未验证的数)。
- **凭证**:每个回答带 {值, 策略, 调整集, 校正的混杂偏差, pgmpy 独立复算+match, 假设, 边界}。

## 3. 为什么这是"下一阶段"
此前三柱是分立证据;此前的 OS 层只是路由原型。现在:**每个有结果的输出都是引擎算的且 pgmpy 独立验证的;每个不可识别/超范围的查询都被拒答而非猜测;每个答案带可审计凭证。** 这是"可验证正确性"作为**统一运行时纪律**的第一个可运行实例——不是三个实验,是一个系统的一次循环。

## 4. 边界(诚实)
- 库为演示模型(4 个机器验证结构 + 示意 CPT),非真实知识库;检索是关键词/签名匹配,非语义嵌入(真实系统需 embedding + 因果签名双层,接 NOTE-014)。
- 同一条边界三柱通用:凭证证"给定结构下精确",**不**证结构/校准对(NOTE-004/010/014)。
- 这是**演示系统**,不是生产 OS;它证明的是"三柱可在一次带凭证的循环里咬合",不是"已可部署"。

## 5. 结论
OS/集成柱从"纯路由原型"前进到"**可运行的三柱凭证化认知闭环**"——The One 第一次作为一个系统跑起来:回答可验证、拒答可计算、保留可审计。
