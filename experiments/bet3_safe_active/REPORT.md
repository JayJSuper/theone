# REPORT — 赌注③（重打地基后）：安全约束主动实验的「安全溢价」是一条可调的帕累托前沿

**日期**: 2026-06-14 | **依据**: Jack Q-C36/37/38（bet③ 概念重打地基）| **无 API，纯仿真**
**复现**: `python experiments/bet3_safe_active/run.py`（δ 扫描：改 `DELTA`）| **真实度**:【已验证·最小模型】

## 0. 一句话
经典结论"主动 vs 被动省样本"**不是**我们的主张（active_loop_min 已诚实复现、不声称新颖）。本实验测 Jack 重定义的真增量——**干预规划安全**：用当前后验**预测**每个候选干预的效应、排除预测有害者。参照是**无约束主动**（非被动）。结果：安全约束把有害干预执行**砍掉 54–94%**（按阈值 δ 可调），代价是对近阈值干预的估计变差——一条**可调的安全/学习帕累托前沿**，safe-active 在该前沿上**支配**无约束主动。

## 1. 设置（最小模型）
k=12 个候选干预 do(Xᵢ)，真效应 θᵢ~N(0,1)，**有害**当 θᵢ≤τ(=−0.5)；执行有害干预即计一次"伤害"。每臂高斯后验从带噪观测更新。预算 T=60。
- **unconstrained-active**：选后验 std 最大（纯信息增益）。
- **safe-active**：排除后验 P(θᵢ≤τ)>δ（预测有害）者，在余下选 std 最大；若全排除则取最安全者（观复 fallback）；不确定即保守按危险处理。
- **passive**：随机（样本效率参照）。

## 2. 结果（40 seeds）
| 策略 | 有害执行次数 | 安全臂 MSE |
|---|---|---|
| passive | 18.3 | 0.100 |
| unconstrained-active | 19.4 | 0.090 |
| **safe-active (δ=0.3)** | **1.1（94% 更少，39/39 seed）** | 0.726 |

**δ 调出的帕累托前沿**：
| δ | 有害执行 | 安全臂 MSE |
|---|---|---|
| 0.1–0.3 | 1.1（−94%） | 0.726 |
| 0.4 | 6.3（−68%） | 0.168 |
| 0.7 | 9.0（−54%） | 0.129 |
| 无约束（参照） | 19.4 | 0.090 |

## 3. 诚实判读（不是免费午餐）
- **安全溢价真实且大**：相对无约束主动，有害干预砍掉 54–94%，全 39/39 seed 成立。这正是 Q-C37 定义的"干预规划安全"——参照是无约束主动，不是被动。
- **有代价**：保守排除近阈值干预 → 它们估计不足 → 安全臂 MSE 升高（δ=0.3 时 8×；δ=0.7 时仅 1.4×）。**没有免费安全**：避开看起来危险的，就学不到它们。
- **可调、且支配**：δ 旋钮在"安全 vs 学习"间连续取舍。在**任一**安全档，safe-active 比无约束少执行大量有害干预；δ=0.7 时以近乎相同的 MSE（0.129 vs 0.090）仍砍掉 54% 有害——对无约束主动构成帕累托改进。
- **取舍是否值得=领域相关**：医疗（伤害代价极高）选低 δ；低风险场景选高 δ。引擎的角色是**给出这条前沿 + 可审计的干预选择凭证**，让领域专家在知情下选点。

## 4. 边界与下一步（Jack 三层只做了第一层）
- 本实验是**最小 bandit 式模型**，演示"干预规划安全"原理，非完整因果结构学习系统。
- **只做了三层中的第一层**（干预规划安全）。未做：**元认知安全**（结构后验高熵→切观复模式，Q-X1）、**双编码器灵敏度锁**（两个独立编码器交叉验证安全判定）。
- 早期后验来自先验、可能误判安全——本模型已含"不确定即保守"，但完整版需双编码器锁（Jack Q-C37）。
- **合并 bet③ 入因果发现**（Jack Q-C38）：本实验是因果发现的**安全数据采集**腿；引擎角色=上游实验设计的效应预测器 + 下游结构凭证，不进结构搜索核心。

## 5.b 第三层：元认知安全切换（`metacog_switch.py`）—— 不确定即收手
Jack Q-C37 第三层 / Q-X1 观复：当学习者**对自己的安全判断不可靠**（该臂后验 std 高 且 均值贴近危险阈值 τ）时，**收手**——切到观复（观测一个已知安全臂），而不是凭一个不可靠的信念去执行。指标=**"误判为安全的有害执行"**（因相信安全而执行、实则有害的"自信安全错误"）。

| δ（约束松紧） | safe-active 自信安全错误 | +metacog | 降幅 |
|---|---|---|---|
| 0.30（紧） | 0.21 | 0.20 | 6% |
| 0.50 | 7.4 | 4.0 | 46% |
| 0.70 | 9.4 | 4.0 | 58% |
| 0.85 | 12.4 | 4.1 | 67% |
| 0.95（松） | 14.7 | 4.2 | **71%** |

**诚实结论**：约束紧时元认知**冗余**（6%，基础约束已够保守）；约束松时元认知**必需**——**无元认知时自信安全错误随约束放松无上界增长（0.2→14.7），有元认知则恒被压在 ~4**。即"知道自己不知道"提供了一个**鲁棒性地板**：当基础安全策略被调得过松（或先验失准），元认知层封顶了它的损害。这正是元认知支柱的价值——不是平均提升，是对"坏调参/坏先验"的兜底。

## 6. 结论（更新）
bet③ 的真增量不是"主动比被动好"（经典），而是三层【全部完成 2026-06-18】：①**安全约束主动实验**在"少碰禁区"上支配无约束主动（可调可审计前沿，§3）；②**双编码器灵敏度锁**（`dual_encoder_lock.py`）——IPRG 在安全判定上的应用，两个独立编码器一致才执行，自信安全错误 0.74→**0.00**（100% 消除，58/58 seeds，比元认知更强）；③**元认知安全切换**——不确定即收手，封顶自信安全错误（§5.b，降 71%）。三层都与 The One 凭证/元认知哲学一致：独立交叉验证 + 不确定即收手，给出可验证的安全保证，而非凭不可验证的自信行动。第②③层同时点亮"校准元认知"支柱。
