# REPORT — 因果发现前沿：观测可发现、隐混杂不可发现（赌注③ 为何存在）

**日期**: 2026-06-14 | **柱**: 因果发现（最后未证边界,bet③ 并入） | **无 API** | **真实度**:【已验证·最小模型】
**复现**: `python experiments/causal_discovery/run.py`

## 0. 一句话
引擎给定结构算 do();真实部署要先从数据**学结构**。用打分式结构学习(pgmpy HillClimbSearch)从已知混杂 SCM 的数据学结构、再在**学到的结构**上算 do(X=1):**混杂可观测时,数据越多 do 越准(0.125→0.062);混杂隐变量时,do 锁死在混杂偏差(~0.15)、再多数据也修不好。** 这是部署的命门,也是 NOTE-004 的活体形态——凭证证"在学到的结构上计算精确",不证"结构(无隐混杂)是对的"。**这恰恰解释了为什么需要主动干预(赌注③)。**

## 1. 结果（do(X=1) 在学到的结构上 vs 真 do,15 seeds）
| n | 混杂可观测 | 混杂隐变量 |
|---|---|---|
| 200 | 0.125 | 0.154 |
| 1000 | 0.116 | 0.164 |
| 5000 | **0.062 ↓** | **0.149（平）** |

- **可观测**：误差随 n 下降（0.125→0.062）——结构被恢复(实测 HillClimb 恢复 U→X,U→Y,X→Y)，do 向真值收敛。剩余非零=结构学习+有限样本 CPT 残差。
- **隐变量**：误差**不随 n 下降**(~0.15 平)——结构学成 X→Y,do 塌成混杂的观测估计,**自信错误、数据修不好**。这是隐混杂的根本壁垒。

## 2. 这把整条因果弧收成一个连贯整体
- **① 给定结构算效应**：强（命门 + 生态效度）。
- **发现（本报告）**：混杂可观测→数据足够即恢复→do 收敛;**隐混杂→学错结构→do 自信错、数据不可修**。这是真实世界部署的门。
- **③ 主动干预**：正是**解药**——干预数据打破隐混杂死锁(观测数据做不到,这是 RCT/干预存在的根本原因)。
- **凭证**：必须声明"结构学自观测数据,隐混杂未排除";发现的输出须带**结构不确定性**,不能只在点估计结构上算。

## 3. 诚实边界
- 最小模型(三节点混杂三角,二元);打分式发现(HillClimbSearch + BIC),非全谱(PC/FCI/score-based 各有脾性)。FCI 类方法能**检测**隐混杂的存在(输出双向边),但不能**消除**其对 do 的偏差——本实验测的是"在发现的 DAG 上算 do"的下游误差,这个壁垒对所有仅观测方法成立。
- 可观测情形的残差(0.062@n=5000)含结构学习的 Markov 等价/有限样本噪声,非零但单调下降——与隐变量的"平"形成关键对比。
- 同一条边界三柱通用(凭证不保结构/校准)——发现是它最尖锐的体现。

## 4. 结论
因果发现前沿点亮:**观测数据可发现结构(数据足够→do 收敛),但隐混杂不可由观测数据消除(do 自信错、数据不可修)**。这是 The One 落地真实世界的决定性瓶颈,也从根本上**解释了赌注③(主动干预)的必要性**——干预是打破隐混杂死锁的唯一途径。整条因果弧(①给定结构→发现学结构→③干预破死锁→凭证声明假设)由此连贯闭合。
