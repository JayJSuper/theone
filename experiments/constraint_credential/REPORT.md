# REPORT — 约束凭证:把可审计标准第4条从"声明边界"扩展到"核验边界"(融合启发③)

**日期**: 2026-06-17 | **类型**: 融合实验(The One 凭证 × 外部构想 EBM 的可验证交点) | 自主长跑产物
**复现**: `.venv/bin/python experiments/constraint_credential/run.py`

## 0. 一句话
外部 AGI 构想用 EBM 给"物理不可能路径"赋无穷能量来拦截——但那是**软神经惩罚、不可第三方核验**。我们把同一思想做成**可验证版**:给每个因果输出附一组**确定性、任何人可重算的可容许性不等式**(bounds∈[0,1]、声明的单调方向、归一化),作为"可验证的 EBM"。它把可审计因果推断标准的第4条(声明区制/边界)从**声明**升级为**核验**。

## 1. 结果
| 来源 | do(X=1) | bounds | monotone(声明正) | 判决 |
|---|---|---|---|---|
| 引擎(正常 SCM) | 0.669 (>do0=0.307) | PASS | PASS | **ADMISSIBLE** |
| LLM 悬崖输出(§6.3) 1.0179 | — | **VIOLATED** | PASS | **INADMISSIBLE → 拒答/标红** |
| LLM 悬崖输出(§6.3) 1.28 | — | **VIOLATED** | PASS | **INADMISSIBLE → 拒答/标红** |
| 引擎(误设 SCM,符号翻转) | 0.319 (<do0=0.657) | PASS | **VIOLATED** | **INADMISSIBLE → 拒答** |

## 2. 两个关键论点
- **catch LLM 自己不 flag 的物理不可能**:§6.3 记录 gpt-5.1 在悬崖处输出 P=1.0179、1.28(概率 >1,数学不可能),且**无警告**。约束凭证用一行不等式 `0≤v≤1` 自动判为 INADMISSIBLE。这是文档"EBM 拦截非物理"的可验证落地。
- **catch 纯"计算精确"凭证会放行的误设**:误设 SCM(效应符号被翻转)下,引擎**计算完全精确**(do(X=1)=0.319 是该错误结构上的精确值),所以只认证"计算精确"的凭证会 PASS;但约束凭证发现它违反**声明的领域单调性**(声明正效应、实得负),判 INADMISSIBLE → 拒答。**这正是把可审计标准第4条从"声明结构/区制"推进到"核验输出是否违反声明约束"。**

## 3. 与可审计标准的关系
原标准第4条(declared regime & boundary)只要求**声明**假设(结构给定、CPT 区制)。约束凭证把它扩展为**声明 + 自动核验**:任何违反声明领域约束(物理 bounds、单调方向、守恒/归一)的输出,无论来自 LLM 的不可能值还是误设结构的精确值,都被确定性、可第三方重算地判为不可容许。仍是**最小标准**:满足约束不保证为真(结构仍可错),但违反约束**确定**为不可接受。

## 4. 边界
- 当前实现三类约束(bounds/monotone/normalised);真实领域约束(守恒律、嵌套单调、剂量-反应形状)可同构扩展。
- 约束需领域声明(谁声明"该效应为正"?)——这是诚实的人类输入点,不是系统自动发现(发现是因果发现柱的事)。
- 这是凭证机制的扩展,非新科学;价值在把"物理合理性"从软惩罚变成可审计核验。
