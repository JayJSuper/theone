# REPORT — 主权记忆柱：记忆的"因果悬崖"与跨柱统一

**日期**: 2026-06-14 | **柱**: 主权持久记忆（The One 第二支柱）| **无 API，纯仿真** | **真实度**:【已验证·最小模型】
**复现**: `python experiments/memory_causal_cliff/run.py`

## 0. 一句话
为**因果决策**检索记忆时，扁平向量相似度（cosine）按**表面关联**排序——在混杂下它系统性捞出"关联相似但因果不同"的记忆、迁移错误的效应；带**因果凭证**的检索按**去混杂的因果签名**排序，误差**与混杂无关、恒为凭证噪声地板**。混杂越强，扁平越错（σ=2 时差 14.4×），凭证检索全程平。**计算柱的因果凭证，使记忆柱可验证地正确——跨柱统一的第一个实证。**

## 1. 设置（最小模型）
记忆库 M=200，每条记忆=一次过去干预，存：真因果效应 c（后门调整后）+ 表面关联 a=c+混杂偏移。新查询要它的因果效应 c_q，只观测到关联 a_q，并经凭证得到去混杂估计 ĉ_q(≈c_q+0.1 噪声)。
- **扁平检索**：取 a 最近的记忆，迁移其 c。
- **凭证检索**：取因果签名 c 最近(匹配 ĉ_q)的记忆，迁移其 c。

## 2. 结果（迁移因果效应的 MAE）
| 混杂 σ | 扁平(cosine) | 凭证 | 扁平/凭证 |
|---|---|---|---|
| 0.00 | **0.010** | 0.079 | 0.1×（扁平胜） |
| 0.25 | 0.263 | 0.079 | 3.3× |
| 0.50 | 0.485 | 0.079 | 6.2× |
| 1.00 | 0.825 | 0.079 | 10.5× |
| 1.50 | 1.013 | 0.079 | 12.9× |
| 2.00 | 1.129 | 0.079 | 14.4× |

## 3. 三个结论
1. **零混杂时扁平检索更优**（0.010 vs 0.079）——关联即因果，凭证的去混杂噪声反成累赘。**这正解释了 WEAK-02**："因果感知检索平均无优势"，因为那批测试域低混杂。
2. **混杂增强→扁平系统性失败**：迁移错误的因果效应，误差随混杂无上界增长。凭证检索**恒平**（0.079=凭证噪声地板，与混杂无关）。
3. **同一个项目形状**：记忆柱的价值不是"平均检索更准"（稠密向量的主场，像线性高斯之于金融、低 k 之于引擎），而是**"在混杂这个因果决策真正需要小心的 regime 里，可验证地正确"**。

## 4. 跨柱统一（The One 灵魂的第一个实证）
凭证检索之所以免疫混杂，是因为它用的是**计算柱产出的去混杂因果签名（凭证）**，而非表面关联。**计算柱的可验证正确性，向上传递成了记忆柱的可验证正确性。** 这是"可验证正确性"作为统一原则、跨柱闭环的第一个具体证据——不再只是架构口号。凭证检索的误差由**凭证质量**（可控）决定，而非由混杂（不可控的表面属性）决定。

## 5. 边界
- 最小仿真：凭证给的是带 0.1 噪声的去混杂签名；演示原理（因果签名检索免疫混杂驱动的检索错误），非完整记忆系统（无真实 embedding、无持久化/主权层）。
- 主权记忆的其他面（持久化、用户拥有、可移植、规模检索）未触——本实验只点亮"因果凭证→可验证检索"这一核心机制。
- 凭证检索的地板=凭证质量；若凭证本身错（结构错/校准错，NOTE-004/010），检索也会精确地错——同一条"凭证不保结构"边界沿用。

## 6. 结论
主权记忆柱的第一个真实结果:**带因果凭证的记忆检索，在混杂 regime 下对因果迁移可验证地正确，扁平向量检索系统性失败**;且其正确性**继承自计算柱的凭证**——跨柱统一被实证。记忆柱从"一个弱原型(WEAK-02)"前进到"有一个清晰的、与全局同形的价值主张 + 跨柱证据"。
