# REPORT — 机制探针(跨模型):悬崖有两种微观起源,引擎绕开两者(二次自我证伪)

**日期**: 2026-06-17 | **类型**: 机制实验(自主回答"相变机制",不等外部专家) | **IPRG**: PASS (4.96e-7)
**复现**: `cliff_mechanism/run.py`(gpt-5.1) + `run_deepseek.py`(deepseek-v4-flash)

## 0. 一句话(经两次自我证伪后的诚实定论)
"悬崖随推理预算后移吗?"——答案**模型相关,且第一轮在 gpt-5.1 上得出的"不后移=能力墙"不可普适**:
- **gpt-5.1(reasoning model):悬崖不随预算后移**(2k→32k 恒 k5),且悬崖处即使给 32k 也**只用 ~4k token 就停**——这是"**过早自信终止墙**"(不是算力不足,是不把预算用于精确边缘化)。
- **deepseek-v4-flash(flash model):悬崖随预算后移、到 32k 完全消失**(k3/4/5 全满分),k5 处**用满 17k token**——这是"**预算墙**"(给够就老实算满)。

**两种微观起源(预算耗尽 vs 过早终止),一个宏观现象(未完成精确边缘化)。**

## 2. 二次自我证伪(放下我自己的"能力墙")
第一轮只测 gpt-5.1,得出"悬崖=能力/架构墙、非预算"(写进 §7/NOTE-023)。deepseek 把它**证伪为不可普适**:对 flash 模型,悬崖确实主要是预算墙(4k 下崩 = 部分是截断,给 32k 恢复)。**最尖锐的对照**:同一个 k5,deepseek@32k 用满 17k token→满分,gpt-5.1@32k 只用 ~4k→崩。差别不在"谁强",在**模型是否把可用预算真正投入串行边缘化**。

## 3. 对论文头条的诚实影响(削弱强版本、强化精确版本)
- **削弱**:"组合悬崖普适且纯计算性"的**强版本**被精炼——我们主悬崖实验用固定 4k 预算;给 deepseek 32k,它在 k≤5 恢复精确,故 4k 下的 deepseek 崩**部分是预算不足**,非纯"算不动"。论文必须加此 caveat。
- **强化(更难反驳的版本)**:悬崖由"模型实际投入的串行计算量"决定。要让 LLM 算对 k5,deepseek 需 **17k token**(且 flash 模型才肯花),gpt-5.1 这类 reasoning model **根本不肯花**(给 32k 只用 4k、仍崩)。**而引擎精确 + 0.07s + ~0 token + 可验证、永不过早终止也永不预算耗尽。** 论点从"LLM 算不动"精炼为"LLM 要么不投入(gpt)、要么投入极昂贵(deepseek 17k token),引擎两者都绕开"——这正是启发④"可验证+低能耗"联合主张的硬证据(17k token vs ~0)。
